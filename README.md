## Featured Projects

**🍽️ [HomeBite](https://github.com/PNair05/homebite)**
An iOS app (SwiftUI) that lets university students discover, buy, and sell home-cooked meals from other students on campus. Includes role-based flows for customers, cooks, and sellers, a map/list meal finder with scheduled pickups, and an async REST layer wired to a FastAPI backend.
`Swift` · `SwiftUI` · `Python` · `FastAPI` · `MVVM`

**🎙️ [Intervista++](https://github.com/PNair05/interview_prep_mcp)**
An adaptive mock-interview platform that builds context on a candidate — GitHub, resume, target job posting — and runs a LangGraph ReAct agent on Gemini to generate and adjust technical and behavioral questions live. Includes voice interaction via ElevenLabs (TTS/STT), an answer-scoring engine, MongoDB persistence, and an MCP-compliant JSON-RPC/WebSocket API so other tools can plug in.
`Python` · `FastAPI` · `LangGraph` · `Gemini` · `MongoDB` · `ElevenLabs` · `MCP`

**⚡ Redis Server**
A multithreaded, in-memory key-value store in C++ that mimics Redis, built on POSIX socket programming over TCP/IP to handle concurrent client connections. Hand-rolled a RESP protocol parser, made command execution thread-safe with mutex locks, built the storage engine on STL hash tables and vectors for O(1) lookups, and added file-I/O snapshotting plus POSIX signal handling for persistence and graceful shutdowns.
`C++` · `POSIX Sockets` · `TCP/IP` · `Multithreading`

**🧭 Synthesis**
An AI-powered product discovery platform (Next.js 14, TypeScript, Tailwind CSS) with a glassmorphism UI and real-time charts. A Python backend orchestrates multiple LLMs (Llama 3, Mistral) to turn unstructured user feedback into technical specs and implementation prompts, then pushes them straight into Jira and Figma — cutting product planning cycles by roughly 90%.
`Next.js` · `TypeScript` · `Tailwind CSS` · `Python` · `Jira API` · `Figma API` · `LLMs`

**🩺 Medi-bot** — 🏆 1st Place, TAMUHack
A voice-driven first-aid assistant pairing STT/TTS pipelines with an LLM to give hands-free emergency instructions, backed by a custom validation framework that filters AI-generated medical advice to prevent hallucinations. Also drives a low-latency link to an SO-101 robotic arm to physically retrieve and dispense medical supplies.
`LLMs` · `Speech-to-Text` · `Text-to-Speech` · `Robotics` · `Safety Guardrails`

**🎯 Picky** — Co-Founder, Product Design
An event discovery platform that connected 200+ users with shared interests, holding 35% weekly active user retention. Built a Python/Selenium scraper that ingested event data from multiple sources into Supabase (PostgreSQL), cutting roughly 100 hours/month of manual data entry, and drove product strategy and go-to-market through user interviews and iterative validation.
`Python` · `Selenium` · `Supabase` · `PostgreSQL` · `Product Strategy`
